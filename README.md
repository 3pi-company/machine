# machine

محرك السحب العام لمكتب 3pi — **كود بس، صفر بيانات عميل**. بيسحب من جوليب لصالح لوحتي
الرشيدي (C-0002) وعلي الصياد (C-0001)، وبيكتب النتيجة (مخزون خام + ملف صحة) في فرع `data`
بتاع كل ريبو خاص بالعميل، ثم يطلب من الريبو الخاص يبني لوحته وينشرها (بدون أي سحب من جوليب هناك).

## ليه الريبو ده عام؟
دقايق GitHub Actions المجانية للريبوهات الخاصة محدودة (2,000 دقيقة/شهر للمنظمة كلها)، وخطوة السحب من
جوليب بطيئة (فاصل 3 ثواني بين كل طلب). الريبوهات العامة عندها دقايق GitHub Actions مجانية غير محدودة.
فبننقل الجزء البطيء (السحب) هنا، ونسيب الريبو الخاص يعمل بس البناء والنشر (سريع، صفر طلبات جوليب).

**لا يوجد أي سر ولا بيانات عميل في هذا الريبو نفسه** — فقط كود بايثون للقراءة (GET/search_read فقط)،
وملف الصحة الناتج (أرقام وحالة بس، بدون أسماء أو مبالغ). الأسرار (مفاتيح جوليب، وتوكن الدفع للريبوهات
الخاصة) محفوظة كـ GitHub Actions secrets في هذا الريبو نفسه — ومحجوبة تلقائيًا عن أي PR من فورك
خارجي (الإعداد الافتراضي لـGitHub: الفحوصات من الفروك محتاجة موافقة يدوية وما بتشوفش الأسرار).

## البنية
- `c0002/` — كود سحب الرشيدي (REST: sync.py، وقارئ المخزون المقيّد: stock_pull.py + stock_web.py)
- `c0001/` — كود سحب علي الصياد (جلسة ويب للقراءة فقط: pull_sales.py + juleb_web.py)
- `.github/workflows/sync.yml` — دورة واحدة كل 15 دقيقة: تسحب الاتنين بالتوازي، تكتب النتيجة في فرع
  `data` بتاع كل ريبو خاص، وتبعت `repository_dispatch` يشغّل البناء والنشر هناك.

## الأسرار المطلوبة هنا (تُضاف من المالك، نفس قيم الريبوهات الخاصة)
| الاسم | المصدر |
|---|---|
| `CLIENT_C0002_JULEB_URL`, `CLIENT_C0002_JULEB_API_KEY` | موجودين في ريبو c0002-dashboard |
| `CLIENT_C0002_JULEB_DB`, `CLIENT_C0002_JULEB_USER`, `CLIENT_C0002_JULEB_PASS` | لو اتضافوا لريبو c0002-dashboard (الرصيد السالب) |
| `CLIENT_C0001_JULEB_URL`, `CLIENT_C0001_JULEB_DB`, `CLIENT_C0001_JULEB_USER`, `CLIENT_C0001_JULEB_PASS` | موجودين في ريبو c0001-dashboard |
| `PUSH_TOKEN` | توكن بصلاحية كتابة على `3pi-company/c0002-dashboard` و`3pi-company/c0001-dashboard` فقط (نفس قيمة `GH_TARGETS_TOKEN` الموجود عندهم) |

بعد إضافة الأسرار دي هنا، هنوقف جدولة السحب في الريبوهين الخاصين (يفضل كودهم موجود للطوارئ بس)
ويبقى السحب كله من هنا.
